# Borrowing ledger

The experiment is standalone but intentionally small.

- `apparatus/modelio.py`, `apparatus/environment.py`, `apparatus/runner.py`, and `apparatus/execute.py` began from the predecessor implementation at `ScrappyTom/qwen38-context-reduction-pressure-boundary-v0@ab0e21b201d04521a43f83c223a364bca35a7b86` and were modified for recurrent delivery.
- The predecessor's exact parent evidence and two oldest-fit measured cells were materialized under `predecessor_evidence/`. Each copied file retains repository, commit, original path, Git blob, SHA-256, size, copied path, copied hash, and byte-equivalence status.
- The four frozen source documents and two parent candidate fixtures remain inherited evidence. They are not treated as observations produced by this experiment.
- The full model and llama.cpp binaries remain external runtime assets and are hash-locked; no model binary is copied here.

The Custody Cards donor and predecessor repositories are read-only. This repository does not update either project's governance or history.
